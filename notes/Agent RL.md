# Agent RL

### **1. 信用分配（Credit Assignment）**
**核心问题**  
在长序列任务中，传统群体强化学习方法难以对单步动作提供精准反馈，导致信用分配模糊。

**创新方法**  
- **层次化群体结构**：  
  - **轨迹级群体**：基于整体回报评估宏观优势。  
  - **步骤级群体**：利用重复出现的"锚点状态"（anchor state）构建微观组，计算单步动作优势。  
  - **动态融合**：结合宏微观优势，优化策略梯度更新。  
- **异构群体策略**：在多智能体场景中通过分阶段采样（如Round-robin）平衡组内同构与异构样本，实现端到端协作优化。

**实验验证**  
- 在ALFWorld等任务中，步骤级分组使训练效率提升30%+，冗余动作减少50%。  
- 多智能体系统在HotpotQA等任务中准确率提升15%，泛化性优于单智能体PPO。

### **2. 长上下文记忆管理（Memory）**
**核心问题**  
传统方法在处理长文本时面临O(N²)计算复杂度、内存膨胀及信息干扰难题。

**解决方案**  
- **MemAgent**：将长文本分块处理，利用RL训练选择关键信息更新固定大小的记忆库，回答阶段仅依赖最终记忆。  
- **MEM1**：通过端到端RL训练智能体动态压缩内部状态（<IS>），维持常数级内存占用，实现多轮交互效率优化。

**实验结果**  
- MemAgent在3.5M字符长文本中关键信息保留率达78%，优于基线10%。  
- MEM1在复杂任务序列中峰值内存仅增长3%，任务完成率提升20%。

### **3. 多智能体协作（Multi-Agent Learning）**
**核心挑战**  
传统多模型协同训练成本高，且缺乏针对性优化机制。

**创新框架**  
- **MLPO分层框架**：仅训练一个领导者（Leader）模型，协调多个固定参数的协作智能体（Peers）。  
  - **回溯式监督微调**：增强Leader的纠错能力。  
  - **多智能体引导强化学习**：通过群体响应优化Leader的综合决策策略。

**关键成果**  
- 在数学推理（MATH）任务中准确率达76.2%，比单模型高6%。  
- 领导者的动态响应选择机制优于多数投票策略，任务扩展效率提升40%。

## MemAgent: Reshaping Long-Context LLM with Multi-Conv RL-based Memory Agent

### 核心问题
传统长上下文方法On²复杂度，外推时性能下降，LLM在拓展上下文中选择性信息保留困难，缺乏保存关键答案实时同时丢弃干扰因素的科学系动态记忆机制。
### 总结
在QA任务时，任务相关的信息是稀疏的，较为容易判别，理论上可以吧文本分为若干段，使用LLM依次阅读Chunk并且此过程中维护一个与query相关的memory，最后依据这个memory回答问题即可，这个过程可建模为MDP，使用RL进行训练

### 方法
- memory提取过程建模
 - 文本切分成若干chunk，每个chunk大小固定
 - 每次阅读一个chunk，选择重要信息更新到memory中，memory大小固定
 - 根据最后的memory生成query对应的answer
 对LLM的生成模型进行了假设，和传统的LLM只是生成模型有区别
- RL训练
 - 与传统GRPO不同，token-level vs conversion-level 每次 个conversion中，llm对应的context不同
 - 将整个conversion看成MDP，使用最后一个conv产生的memory来获得answer，从而得到reward；，改reward用于优化前序所有的conversion
 - 使用RL是为了让前序所有的conversion都能得到训练
## MEM1: Learning to Synergize Memory and Reasoning for Efficient Long-Horizon Agents
### 核心问题
现有长序列多轮交互系统采用全上下文拼接方式，导致三个关键挑战：(1) 计算成本和内存使用无限增长：Transformer架构O(N²)计算复杂度和O(N)内存使用随上下文长度N线性增长；(2) 训练长度外泛化能力限制：超出训练数据上下文长度的对话变成分布外数据；(3) 冗余信息干扰推理：无关或重复内容稀释模型注意力，降低推理能力。
### 总结
通过端到端强化学习训练智能体学会将推理和记忆整合到统一的内部状态，每个回合的加护更新压缩共享状态并策略性丢弃无关信息，实现跨任意长序列的常数级内存使用。
