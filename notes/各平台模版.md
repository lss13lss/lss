# 各平台模版
可以，下面我直接给你一套**可复制、可长期复用、后续容易个性化修正**的模板。
我会按你已经确定的账号定位来写，也就是：**主角是你本人，AI 是协作者，内容核心是“AI时代的个人成长”**。

---

# 1. 总控模板：一条选题改成四个平台版本

这个模板最重要。
以后你只要把一个主题扔给 AI，就能先产出四个平台的初稿。

```text
你现在是我的跨平台内容改写助手。

我的账号名是：lss在AI时代
账号定位：记录我如何在 AI 时代，借助 AI 重塑学习、工作、表达与生活。
核心要求：主角是“我本人”，AI是我的协作者，内容重点是“我的真实成长、真实实验、真实变化”，不要写成纯AI资讯号、纯工具号或营销号。

现在请你围绕以下主题，帮我分别生成：
1. 抖音版本
2. 小红书版本
3. 公众号版本
4. B站版本

# 本次主题
【填写你的主题】
例如：
- 我最近如何用AI做每周复盘
- AI帮我拆解一个焦虑问题
- 我现在怎么用AI做读书笔记
- 一个AI新功能，普通人到底值不值得用

# 我的真实素材
【填写你的真实经历/过程/结果】
例如：
- 我以前的问题是什么
- 我为什么想解决它
- 我具体怎么和AI协作
- 用了什么提示词/方法/流程
- 最后的效果是什么
- 我有什么真实感受

# 输出总要求
1. 每个平台都要保留同一个核心主题，但表达方式必须符合平台特点
2. 一定要体现“我”的经历、变化和思考
3. AI不能只是背景，要能看出AI具体参与了什么
4. 不要浮夸，不要标题党，不要成功学口吻
5. 语言真实、清晰、有记录感，有成长感
6. 每个平台版本都请输出：
   - 标题
   - 内容定位
   - 开头写法
   - 正文结构
   - 结尾方式
   - 适合搭配的素材形式

# 平台要求
## 抖音
更适合短口播/半口播，节奏快，开头要抓人，突出“一个问题 + 一个变化 + 一个结论”
时长按30-60秒优先
素材可以包括：真人口播、字幕、屏幕录制、聊天截图、少量AI辅助画面

## 小红书
更适合图文为主，短视频为辅
重点是“真实经历 + 过程拆解 + 方法总结 + 感受”
要有可模仿感、可收藏感、可共鸣感

## 公众号
更适合深度长文
重点是把完整过程、逻辑、方法、反思写清楚
要适合沉淀成长期内容资产

## B站
更适合中长视频
重点是“完整过程 + 操作展示 + 反思总结”
适合口播 + 录屏 + 关键步骤演示

请开始输出。
```

# 2. 抖音专用模板

这个适合你已经想好题目，单独让 AI 写抖音口播。

```text
你现在是我的抖音短视频文案助手。

我的账号名是：lss在AI时代
我的定位不是纯AI工具号，而是“AI时代个人成长账号”。
请围绕我的真实经历，把内容写成适合抖音发布的短视频口播稿。

# 本次主题
【填写主题】

# 我的真实素材
【填写真实经历】
包括：
- 我原来的问题
- 我为什么想改变
- 我怎么让AI参与进来
- 我具体怎么做
- 最后结果如何
- 我现在的感受或认识

# 输出要求
请输出：
1. 3个抖音标题
2. 1个30秒版本口播稿
3. 1个60秒版本口播稿

5. 封面文案建议
```

# 3. 小红书专用模板

这个适合你做图文帖，尤其适合你现在的账号。

```text
你现在是我的小红书图文内容助手。

我的账号名是：lss在AI时代
账号定位是：记录我如何在AI时代，借助AI重塑学习、工作、表达与生活。
请把我的真实经历，写成适合小红书发布的图文内容。

# 本次主题
【填写主题】

# 我的真实素材
【填写素材】
包括：
- 我遇到的问题
- 当时的状态/情绪
- 我为什么想到用AI
- 我具体怎么和AI协作
- 我的方法/流程/提示词
- 最后效果和反思

# 输出要求
请输出：
1. 5个小红书标题
2. 一篇完整的小红书图文文案
3. 适合拆成几页图文
4. 每页该写什么
5. 封面标题建议
6. 结尾互动句
7. 相关标签建议

# 风格要求
1. 要真实，不要像广告
2. 要有“我”的存在感
3. 要有过程感，不只是结论
4. 要有一点可复制的方法，但不要写成教程味太重
5. 能让人觉得“这个人是真的在实践”
6. 不要太专业术语化
7. 结尾可以收束到一个小感悟

# 小红书图文结构参考
```

```text
你现在是我的公众号文章助手。

我的账号名是：lss在AI时代
账号定位不是纯AI资讯号，而是“AI时代个人成长账号”。

# 本次主题
【填写主题】

# 我的真实素材
【填写素材】
包括：
- 背景
- 问题
- 触发点
- 我为什么想尝试AI
- 具体协作过程
- 结果和变化
- 我的思考和复盘

# 输出要求
请输出：
1. 5个公众号标题
2. 一篇完整文章
3. 文章结构大纲
4. 文中适合插入哪些图片/截图
5. 文章结尾怎么收束更自然

# 风格要求
1. 不要像新闻稿
2. 不要像纯教程
3. 更像一个人认真讲清楚一段真实经历
4. 有逻辑，有细节，有反思
5. 要突出“AI怎么真正进入了我的生活/学习/工作”
6. 不要只强调工具，而要强调人的变化
7. 语言克制、真实、有思考

# 文章结构参考
- 开头：我最近为什么一直在想这个问题
- 第一部分：我原来的状态和困境
- 第二部分：我为什么决定让AI参与进来
- 第三部分：我具体是怎么做的
- 第四部分：实际结果和变化
- 第五部分：我对这件事的新理解
- 结尾：留一个开放感的结尾，不要强行升华

请按这个要求输出。
```

# 6. 二次修正模板

你拿到 AI 的初稿后，不可能一次就满意。
这个模板是给你“二次打磨”用的。

```text
请基于你刚才生成的内容，继续优化，但不要偏离“lss在AI时代”的账号定位。

重点优化以下问题：
1. 现在这版还不够像“我本人”，请加强我的真实感
2. 现在这版有点像工具教学，请增加“成长变化”和“个人思考”
3. 现在这版有点泛，请补充更具体的场景和细节
4. 现在这版太像AI资讯号，请减少空泛信息，增加我和AI的真实互动
5. 现在这版语气有点像老师，请改得更像一个正在成长中的人
6. 现在这版结尾太硬，请改得更自然一点
7. 现在这版太长/太短，请调整到更适合【平台名】的长度

请输出优化后的完整版本，并说明你重点改了哪些地方。
```

# 8. 一套你后续最好一直保留的“固定补充指令”

你以后每次在任何模板后面，都可以再加这段，会让 AI 产出的内容更稳定。

```text
补充要求：
1. 不要把内容写成纯AI教程
2. 不要让我本人消失
3. 一定要体现“AI如何参与了这件事”
4. 一定要体现“我在这件事里的变化”
5. 不要夸张，不要标题党，不要成功学
6. 不要像营销号
7. 优先写得像真实记录，而不是标准答案
8. 能写具体就不要写空话
9. 要符合“lss在AI时代”的长期账号定位
```

# 9. 你最推荐的使用方法

我建议你以后这样用：

### 第一步

先用“总控模板”
把一个主题拆成四个平台版本。

### 第二步

再拿其中一个平台版本
用对应的“平台专用模板”单独细化。

### 第三步

不满意的时候
用“二次修正模板”继续改。

这样比你每次重新解释一遍账号定位轻松很多。
