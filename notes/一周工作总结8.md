## 文档导入

文档导入相关接口：
文档导入知识库，分为本地文档和iwiki文档两类，本地文档需要先进行上传，得到url
### 文档上传：
- **URL**: `/api/v1/files`
- **Method**: `POST`
- **Content-Type**: `application/json`
##### 请求参数
| | | | | |
|:-:|:-:|:-:|:-:|:-:|
|参数名|位置|类型|是否必需|描述|
|`file`|Path|File|是|需要上传的文件。|
|`ragCode`|Path|String|是|实例code。|
##### 请求体

```
{
	"key": "file",
	"type": "file",
	"src": "/Users/evanjwliang/Downloads/07f7888f-4736-4294-a517-9ecfaa668880.md" //文件地址
},
{
	"key": "ragCode",
	"value": "is-6421ac2c",                                                      //实例代码
	"type": "text"
}
```
**字段说明:** 仅需提供要修改的字段。
##### 响应体
返回上传后的文档信息，主要需要拿到fileName、downloadUrl用于后续的导入操作，其他信息存入数据库中

拿到文档的url后开始进行导入知识库，如果文档类型非markdown需要进行类型转换，iwiki文档也要转换成markdown类型，
### 文档导入:
- **URL**: `/api/v1/documents`
- **Method**: `POST`
- **Content-Type**: `application/json`

##### 请求参数
| | | | | |
|:-:|:-:|:-:|:-:|:-:|
|参数名|位置|类型|是否必需|描述|
|`type`|Path|String|是|需要导入的文件类型，分为file和iwiki。|
|`fileName`|Path|String|是|文件的名称，必须带拓展名，用于判断文件类型|
|`url`|Path|String|是|文件的下载链接，type为file就是使用files上传得到的downloadUrl，type为iwiki就是iwiki的链接(需要保证iwiki的权限中包含venus_aigc)|
|`fragmentationConfig`|Path|String|是|存储了需要导入的trag信息和文件切分需要的参数|
| `ragCode` | Body | String | 是 | 实例code |
| `namespaceCode` | Body | String | 是 | 命名空间code |
| `collectionCode` | Body | String | 是 | 知识库code | 
| `embeddingModel` | Body | String | 是 | 文本嵌入模型名称（如 `bge-large-zh`） | 
| `chunkSeparators` | Body | Array[String] | 是 | 文本分块的分隔符数组（如 `["\n",";"]`） | 
| `chunkSize` | Body | Integer | 是 | 每个文本块的最大长度（字符数，范围 400-8000） | 
| `chunkOverlap` | Body | Integer | 是 | 分块之间的重叠字符数 |

##### 请求体
```
{
  "type": "file",
  "fileName": "upload_11965978819435934830.md",
  "url": "https://venus-llm-1258344701.cos-internal.ap-guangzhou.tencentcos.cn/userUpload/is-6421ac2c/2025-06-26/a7f0247b-2ea0-4067-954e-b2597facc391/a7f0247b-2ea0-4067-954e-b2597facc391.md?q-sign-algorithm=sha1&q-ak=AKID61g5D5fy1TjiRv84nEOHtFJ8gyzjCPL0&q-sign-time=1750904593%3B1750908193&q-key-time=1750904593%3B1750908193&q-header-list=host&q-url-param-list=&q-signature=c81b1bae5b51ee3f05a9da22eb20642488513469",
  "fragmentationConfig": {

    "ragCode": "is-6421ac2c",
    "namespaceCode": "ns-84bcaf29",
    "collectionCode": "col-916ca8ce",

```
##### 响应体
返回是否成功和collection当前的文档片数量

### 文档列表：
- **URL**: `/api/v1/documents`
- **Method**: `GET`
- **Content-Type**: `application/json`
##### 请求参数
| 参数名 | 位置 | 类型 | 是否必需 | 描述 |
|:-:|:-:|:-:|:-:|:-:|
| `ragCode` | Query | String | 是 | 实例code |
| `namespaceCode` | Query | String | 是 | 命名空间code |
| `collectionCode` | Query | String | 是 | 知识库code |
| `retrieveVector` | Query | Boolean | 否 | 是否返回向量数据（默认 false） |
| `limit` | Query | Integer | 否 | 返回结果数量限制（默认 10） |
| `offset` | Query | Integer | 否 | 分页偏移量（默认 0） |
请求示例：
```
curl -X 'GET' \
  'http://api.trag.woa.com/api/v1/documents?ragCode=is-6421ac2c&namespaceCode=ns-84bcaf29&collectionCode=col-7bd03958&retrieveVector=false&limit=5&offset=10' \
  -H 'accept: */*'
```
##### 响应体
会返回存储文档片段的详细信息
### 文档检索：
通过检索功能召回与输入query相关的文档片段
分为search和mulit-search，multi-search可以指定多个collection进行检索。

- **URL**: `/api/v1/documents/search`
- **Method**: `GET`
- **Content-Type**: `application/json`
##### 请求参数
| 参数名 | 位置 | 类型 | 是否必需 | 描述 |
|:-:|:-:|:-:|:-:|:-:|
| `ragCode` | Query | String | 是 | 实例code |
| `namespaceCode` | Query | String | 是 | 命名空间code |
| `collectionCode` | Query | String | 是 | 知识库code |
| `doc` | Query | String | 是 | 搜索关键词/内容 |
| `embeddingModel` | Query | String | 否 | 嵌入模型名称，不填默认匹配对应collection使用的模型 |
| `retrieveVector` | Query | Boolean | 否 | 返回向量数据（默认 false） |
| `limit` | Query | Integer | 否 | 返回结果数量限制（默认 10） |
| `enableSentence` | Query | Boolean | 否 | 启用句子级搜索（默认 false） |
| `enableRerank` | Query | Boolean | 否 | 启用重排序功能（默认 false） |
| `reRankModel` | Query | String | 否 | 重排序模型名称（需 enableRerank=true） |
| `withQueryInstruction` | Query | Boolean | 否 | 包含查询指令（默认 false） |
| `skipShardingKeyFilter` | Query | Boolean | 否 | 跳过分片键过滤（默认 true） |
| `embeddingWithCache` | Query | Boolean | 否 | 使用缓存嵌入（默认 true） |

请求示例
```
curl -X 'GET' \
  'http://api.trag.woa.com/api/v1/documents/search?ragCode=is-6421ac2c&namespaceCode=ns-84bcaf29&collectionCode=col-7bd03958&doc=大语言模型的技术原理&embeddingModel=bge-large-zh&retrieveVector=false&limit=10&enableSentence=false&enableRerank=false&reRankModel=bge-reranker-large&withQueryInstruction=false&skipShardingKeyFilter=true&embeddingWithCache=true' \
  -H 'accept: */*'
```
##### 响应体
返回检索到的文档片段信息

- **URL**: `/api/v1/documents/multi-search`
- **Method**: `GET`
- **Content-Type**: `application/json`
##### 请求参数
| 参数名 | 位置 | 类型 | 是否必需 | 描述 |
|:-:|:-:|:-:|:-:|:-:|
| `ragCode` | Query | String | 是 | 实例code |
| `namespaceCode` | Query | String | 是 | 命名空间code |
| `collectionCodes` | Query | List<String> | 是 | 知识库列表（多个用逗号分隔） |
| `docs` | Query | List<String> | 是 | 搜索内容列表（多个用逗号分隔） |
| `policy` | Query | String | 否 | 策略名称 |
| `embeddingModel` | Query | String | 否 | 嵌入模型名称 |
| `retrieveVector` | Query | Boolean | 否 | 是否返回向量数据（默认 false） |
| `limit` | Query | Integer | 否 | 文档结果数量限制（默认 10） |
| `pageNum` | Query | Integer | 否 | 分页页码 |
| `pageSize` | Query | Integer | 否 | 每页结果数量 |
| `selectFields` | Query | List<String> | 否 | 返回字段列表（多个用逗号分隔） |
| `filterExpr` | Query | String | 否 | 前置过滤表达式 |
| `shardingKey` | Query | String | 否 | 索引存储分片键 |
| `skipShardingKeyFilter` | Query | Boolean | 否 | 跳过分片键过滤（默认 false） |
| `context` | Query | JSON | 否 | 历史上下文记录 |
请求示例：
```
curl -X 'GET' \
  'http://api.trag.woa.com/api/v1/documents/multi-search?ragCode=is-6421ac2c&namespaceCode=ns-84bcaf29&collectionAliases=java-guide,database-tutorial&docs=JDBC连接池配置&context=%5B%7B%22query%22%3A%22MySQL驱动安装%22%7D%5D&filterExpr=doc_type%3D%22tutorial%22' \
  -H 'accept: */*'
```
