## 一、为什么换

| | AI 文生图 | 手写 SVG（前两版） | **HTML/CSS → 截图** |
| --- | --- | --- | --- |
| 中文标注 | 假字／乱码 | 准确 | 准确 |
| 平台水印 | 自动带，需后期抹 | 无 | 无 |
| 配色排版自由度 | 靠提示词碰运气 | 低，要手算坐标 | 高，字体／网格／渐变／阴影随手调 |
| 改一个词 | 重生成 | 改坐标 | 改 HTML 重截，几秒 |
| 与网站风格统一 | 难 | 易 | 易 |
| 产物体积 | 1–2.6 MB | 2–3 KB | 35–81 KB（WebP 无损） |

一个要记住的澄清：**前两版被否定的 SVG 本质也是「用代码画图」**，问题在设计（同色系、信息密、不亮眼），不在技术路线。HTML/CSS 相比手写 SVG 的真正优势是排版效率高，容易做出大色块、大留白、强字号对比。

AI 生图那一路的两个硬伤：中文假字无法承载「表 1」「01/02/03」这类精确标注；平台自动加「AI 生成 / WORKBUDDY」水印，本地抹除后深色渐变图仍有色差方块，最终靠统一裁底边解决。4 张候选（明亮扁平 / 等距科技 / 纸感拼贴 / 高对比左右对比）留在 `~/WorkBuddy/2026-10-26-11-26-03/配图候选-2026-11-05/`，**未上线，也未删除**，可作风面氛围图的备选。

## 三、配图管道

网站项目：`~/WorkBuddy/2026-10-29-23-45-48/optimized-2026-10-30/`

| 文件 | 作用 |
| --- | --- |
| `figure-src/figure.css` | 三张图共用的视觉语言：奶油白 `#FBF8F1`／墨 `#1C2430`／亮黄 `#FFD84D`／朱红 `#E8503A`／灰蓝 `#E8EDF2`，Songti SC 衬线标题 + PingFang 正文 + 等宽小标签，1.5px 硬描边 + 4px 硬阴影。**改配色只动这一处** |

| `figure-src/agent-loop-steps.html` | 图 2 1200×800，四步卡片 + 「写回记录」回环带 |
| `figure-src/render/*.png` | 浏览器 2 倍截图的高清原图（2400 宽），保留可追溯 |
| `assets/*.webp` | 无损 WebP 成品上线件，35 / 62 / 81 KB |

流程：改 HTML → `agent-browser open file://…` → `set viewport <w> <h> 2` → `reload` → `screenshot "#poster" <path>` → Pillow `save(..., "WEBP", lossless=True)` → 走 [[03-项目/个人项目/个人网站-部署通道-2026-11-03|HTTP 上传口]] PUT。

尺寸按网站实际位置定：卡片封面 347×139（2.5:1，`object-fit: cover`）、文章头图 `contain`、正文图宽度自适应（移动端 `min-width: 600px` 横滑 + 点开看大图）。旧 3 张深色 SVG 保留在 `assets/` 作回退，未删除。
