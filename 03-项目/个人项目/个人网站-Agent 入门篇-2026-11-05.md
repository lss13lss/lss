## 四、内容是怎么写的

面向「用过 AI 对话、没用过 Agent、不需要编程基础」的读者，用「帮我安排下周去上海出差」这一个日常请求贯穿。七节依次是：两种交付的差别 → 一句话定义并拆成三件事 → 一轮四步与核对后的分叉 → 三类适合的任务（表格）与做不好的情况 → 怎么给足背景和边界 → 一个可以马上试的小任务 → 站内延伸阅读。

刻意保留的边界：示范请求标明「不是任何产品的效果测试」；写明 Agent 更慢、更费算力、目标模糊时容易偏；「信息给得足也不保证结论对」；不预设加上下文必然更好。延续本站「记录尝试与局限，不做工具新闻」的调性。
