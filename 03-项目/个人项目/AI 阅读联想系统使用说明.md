# AI 阅读联想系统使用说明

> [!summary] 一句话用法
> 在当前读书笔记中选中一个真实段落，再选择另一篇笔记的具体段落；先写自己的联想，在插件内与 AI 讨论后形成当前认识，最后保存为两段文字之间的精确链接。

## 使用前准备

- 当前阅读内容和想到的旧书内容，都需要已经存在于 Obsidian 的 Markdown 笔记中。
- 在当前读书笔记的编辑界面里，选中真正触发联想的一句话或一个段落。
- 不需要先创建“观点文档”，也不需要精确记得旧书原文在哪一节；可以通过插件搜索目标笔记和段落。

## 一次完整的使用流程

### 1. 从当前片段开始

在当前读书笔记中选中文字，然后点击左侧栏的书本图标；也可以打开命令面板，运行“阅读联想：开始一次阅读联想”。

侧栏中的“写入位置”应该显示当前书籍笔记，“当前阅读片段”应该是刚才选中的原文。

### 2. 选择真正相关的旧内容

点击“选择关联笔记和具体片段”：

1. 先搜索并选择想到的那篇笔记。
2. 再从其中选择一个具体标题或段落。

这里建立的是“当前段落 → 目标段落”的联系，不只是笼统地连接两本书。

### 3. 先写自己的原始联想

在“我的原始联想”里，用自己的话说明：

- 为什么会想到另一段内容；
- 两者可能是同一意思、相互解释、因果、类比、冲突，还是其他关系；
- 现在还拿不准的地方是什么。

不必为了写得完整而先检索原文。这个系统默认以人的联想为起点。

### 4. 在插件内与 AI 讨论

点击“带着我的判断开始讨论”，再点击“请 AI 先回应”。插件会直接调用 DeepSeek V4 Flash，不需要复制或粘贴内容。

AI 会先复述你的判断，再用一个简短问题帮助你澄清关系、检查逻辑跳跃和适用边界；除非你明确提出，否则不检索原文，也不主动推荐其他书。

在“我的回答或补充”中继续表达，每次点击“继续讨论”即可获得下一轮回复。插件会自动把这段对话整理进“AI 讨论记录”。

如果仍然不确定书中是否真的这样表达，勾选“这部分以后需要核对原文”。

### 5. 形成当前认识并保存

点击“形成当前认识”，填写：

- **联想标题**：给这次联系起一个便于以后识别的名字。
- **讨论后形成的当前认识**：用自己的话写下现在的判断、适用边界和仍然不确定的地方。

预览无误后，点击“写入当前书籍笔记”。

## 保存后会出现什么

保存一次联想会产生三处可以查看的结果，但不会创建新的观点文件。

### 当前片段旁：直接跳到目标段落

插件会在来源段落下加入一条精确链接：

```markdown
关联观点：[[另一篇笔记#^目标段落|目标段落摘要]]
```

点击它会直接跳到目标段落，不需要再搜索整篇旧笔记。

### 当前书籍笔记末尾：保留完整思考过程

插件会在 `## 阅读联想` 下保存本次记录，包括：

- 来源片段和关联片段的精确入口；
- 我的原始联想；
- AI 讨论记录；
- 讨论后形成的当前认识；
- 是否需要核对原文。

### 目标笔记：通过反向链接返回来源

目标笔记中不会重复插入一条显式链接。打开目标笔记右侧的“反向链接”，可以看到哪些来源笔记连接到了这个段落。

Obsidian 的关系图谱仍按“文件”显示边，所以图上看到的是两篇书籍笔记相连；段落级精度保存在 Wikilink 和块 ID 中。

## 常见问题

### 提示“请先打开一本书的 Markdown 笔记”

先在主编辑区打开准备写入的读书笔记，再重新运行“开始一次阅读联想”。不要只把焦点停留在反向链接、关系图谱或插件侧栏中。

### 提示“请先在当前笔记中选中一个真实片段”

需要先在当前 Markdown 笔记里实际选中文字，再启动功能。只在侧栏中手动粘贴一段文字，不能确定它在原笔记中的位置，也就无法建立精确链接。

### 找不到目标内容

先按书名或文件名选择笔记，再在第二步按关键词搜索其中的标题或段落。目标内容必须已经存在于某篇 Markdown 笔记中。

### 为什么没有生成独立观点文档

这是当前设计：默认先把一次联想保存为段落到段落的精确链接，避免知识库过早碎片化。只有同一个观点反复连接多本书、已经变得相对稳定时，才考虑由人确认后晋升为独立观点实体；这个晋升功能目前还没有自动实现。

## 当前版本边界

- AI 讨论已经可以在插件内完成，默认调用 DeepSeek V4 Flash。
- 桌面端会自动读取 OpenCode 保存的 DeepSeek API Key；也可以在“设置 → 阅读联想”中手动覆盖接口、模型或密钥。
- 暂不自动检索旧书或 EPUB。
- 暂不自动发现相似观点或晋升观点实体。
- 当前先验证“人的联想 → AI 讨论印证 → 精确链接 → 个人认识沉淀”这个闭环是否真正有用。
