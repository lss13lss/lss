# MyContext 适配与检索优化

本页由已有口述记录整理，状态以记录日期为准；没有项目代码也可以建立项目页。原话保留在日志与主题记录中。

## 目标

记录 MyContext 的本地适配、消息处理、个人上下文与项目检索，以及上线相关的工程取舍。

## 当时发现的问题与计划

- 当前适配缺少原版 Agent 的主动实体检索能力。
- 需要检查召回材料是否只有问题，是否应该把问答对作为检索单位。
- 放宽实体数量可能增加上下文长度，需要用实际任务评估收益。
- 当时计划先解决可视化和上线相关问题，再做性能优化；截至本次整理没有新增完成证据。

具体依据：[[01-日志/日报/2026-09-23-晚间交流原文#07 MyContext 缺少 Agent 后的实体检索限制]]、[[01-日志/日报/2026-09-23-晚间交流原文#08 MyContext 检索语料、Embedding 方式与后续计划]]。
