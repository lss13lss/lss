# Final First-Featured Style

Use this reference when the user wants a draft to match the settled style in `首推.md`.

This file captures the latest stable preferences shown in the user's final first-featured article.

## Core Positioning

The account is not a technology-teaching account first.
It is a record of how one ordinary person learns, adapts, and grows with AI.

The center of gravity should be:

- real confusion
- real practice
- real personal needs
- real attempts and optimization

Not:

- technical authority performance
- abstract AI evangelism
- trend summarization for its own sake

## Strong Style Signals

### 1. Start from concrete exposure, then move to internal change

The user likes openings that begin with:

- frequently seeing AI news, tools, and practical sharing
- feeling interested first
- then gradually feeling anxious

This creates a believable progression instead of starting with a dramatic declaration.

### 2. Anxiety is linked to lack of practice, not only to threat

One of the strongest newer signals is:

- the user lacks corresponding real practice scenarios
- the information was not truly absorbed or internalized

This matters because it shifts the problem from "AI is scary" to:

- "I am still watching, not yet practicing"

### 3. The preferred answer is practice rooted in real needs

The user now clearly prefers language such as:

- start from real personal needs
- do not only copy other people's efficiency methods
- work is only one part of life
- do not let work-only use cases narrow thought and creativity

This is an important style upgrade and should appear in future drafts when relevant.

### 4. The account promise should stay grounded

Preferred promise:

- record how I keep learning in the AI era
- record what I did with AI
- record what still needs improvement
- record real attempts

Avoid shifting into:

- "I will teach everyone the best AI methods"
- "I will systematically explain advanced tools"

### 5. End with invitation, but keep it light

The final version still allows a soft invitation:

- if you are also confused
- if you want to see how a normal person integrates AI into real life

But the tone should stay companion-like, not instructive.

## Writing Heuristics

- Prefer "真实需求", "真实尝试", "继续优化" over grand transformation language.
- If the user mentions practice gaps, keep that as a central explanatory thread.
- Let AI be framed as something to integrate into life, not only into work.
- Preserve the ordinary-person perspective; do not upgrade the narrator into an expert persona.

## Output Implications

For `口播版本`:

- keep the emotional transitions clear and speakable
- keep page titles functional and close to meaning

For `文字版本`:

- smooth the logic slightly more
- preserve the same claims without over-expanding

For `视频简介`:

- condense the arc into interest -> anxiety -> reflection -> action
- mention the account purpose in one clean line
