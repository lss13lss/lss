# Output Modes

Choose the closest mode and adapt.

## 1. Short Video Script

Use when the user wants a 30 to 90 second spoken script.

- Open with tension, contradiction, or a hard-earned insight.
- Deliver one core claim fast.
- Keep the number of major points low.
- End with a strong takeaway or next action.

Suggested structure:

1. Hook
2. Problem or misconception
3. Key explanation
4. Example or proof
5. Closing line

## 2. Medium Spoken Script

Use for 2 to 5 minute explanations.

- Let the idea breathe slightly more.
- Add one or two examples.
- Keep transitions audible and natural.

Suggested structure:

1. Hook
2. Why this matters
3. Point one
4. Point two
5. Point three or caveat
6. Closing

## 3. Platform Post

Use for post copy, caption, or social text.

- Make the first two lines carry the angle.
- Keep scanability high.
- Preserve the user's voice even when formatting is concise.

## 4. Longform Draft

Use when the user wants article-like output.

- Keep the user's thought structure intact.
- Use research to support, not replace, the user's angle.
- If the user is known for directness, do not become academic.
