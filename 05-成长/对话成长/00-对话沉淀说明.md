# 对话沉淀说明

这里用来保存我们持续对话后沉淀出的内容。重点不是逐字保存，而是留下对未来真正有用的理解、变化和行动。

## 使用方式

- 每次有价值的对话，形成一则简短的会话摘要。
- 稳定出现的偏好、目标、工作方式与表达习惯，更新到个人画像。
- 可执行的下一步，转入待跟进事项。
- 更深的反思分别链接到 [[05-成长/复盘]]、[[05-成长/思考]] 或 [[05-成长/习惯]]。
- Codex 与 OpenCode 从 [[05-成长/对话成长/上下文系统/BOOTSTRAP|BOOTSTRAP]] 进入这套上下文。
- 每日 Observer 在 13:30 增量读取两端新对话，只把带来源的高价值观察追加到 `OBSERVATIONS.md`；第一阶段不自动修改个人画像和正式规则。
- 原作者的材料只作为 [[05-成长/对话成长/导师/导师使用说明|导师视角]]，不作为我的个人事实。

## 目录约定

- `会话记录`：按日期保存的对话摘要。
- `个人画像`：持续校准、可随时修正的自我理解。
- `待跟进`：从聊天中提取的行动和回看点。
- `上下文系统`：Agent 每次启动时读取的精简入口和工作区索引。
- `导师`：外部参考框架、对照结论和分歧记录。

> [!note] 当前约定
> 你会不定期通过对话做整理、思考和规划；我负责把值得保留的内容沉淀进这里，并随着时间逐步形成更贴近你的理解。
