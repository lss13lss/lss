## 每次如何工作

1. 从 [[05-成长/对话成长/上下文系统/BOOTSTRAP|启动入口]] 进入，完整读 USER 和 CURRENT，再读 COMMUNICATION 的“已确认”部分。
2. 按当前任务加载相应协作规则和相关笔记，不一次读取全部知识库。
3. 做判断或复盘时，检索相关思维方式与个人实践；作者观点、助手整理、用户明确认可分开对待。
4. 需要历史证据时先查观察与相关笔记，必要时才追溯外置硬盘的原始对话。

知识笔记记录“有哪些观点与资料”；正式个人记忆记录“你明确认可什么、希望怎样协作”。目录归类、召回频率或第一人称文字都不能替代个人确认。

## 新内容如何进入记忆

对话 → 提取带来源的观察 → 核对证据与适用条件 → 用户确认 → 更新正式记忆。经过实际使用验证的流程才适合固化成 SOP。

目前没有每篇笔记的召回计数，也没有按频率自动晋升事实或 SOP 的机制。本次整理不新增这些机制。读书心得与思维方法可以进入候选记忆，须区分书中观点、个人理解和实际行动。
