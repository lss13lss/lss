# 常驻卡片

> 每个新会话固定加载本卡片和 [[05-成长/对话成长/个人画像/COMMUNICATION#已确认|已确认的沟通约定]]，用来让 Agent 知道「我是谁、在做什么、库里有什么、什么问题去哪找」。只放标题和指针，不放细节。
> 「现在在推进」由 `tools/read_context.py` 每次从 [[05-成长/对话成长/上下文系统/CURRENT|CURRENT]] 实时抽取（每条的加粗首句加第一个链接），不要在这里手写；其余三节手工维护，改动很少。
> 预览实际输出：`python3 tools/read_context.py`。默认输出（卡片 + 沟通约定）建议不超过约 2200 字（11-09 实测约 1900 字），超过时脚本会提示。

## 库里有什么

- `01-日志/`：晚间口述原文，逐字保存，只追加
- `02-主题/`：可复用的知识与判断（思维方式、AI 与 LLM、工作方法、内容创作、投资）
- `03-项目/`：具体项目的状态与过程（工作项目、个人网站、账号运营）
- `04-读书/`：每本书的主笔记，书中观点、本人理解、实践分开写
- `05-成长/`：反思、表达复盘、对话沉淀；`会话记录/OBSERVATIONS` 是候选观察，不是事实

## 什么问题去哪找

- 通用任务（写代码、查资料）：只用本卡片，不碰个人库
- 个人思考、晚间口述：按 COMMUNICATION 的对应约定，**少检索、多提问**，不主动翻笔记替本人回答
- 继续某件事、问项目进度：CURRENT 对应条目 → 项目页的最新日期状态
- 用读过的书或经验帮我判断：眼前的事实 → `04-读书/`、`02-主题/` 的相关段落，分开标注书中观点、本人理解与实践依据
- 我以前怎么想、后来为什么变：主题主笔记里带日期的原判断与修订 → 必要时再看 `01-日志/` 原话或观察记录
- 详细检索规则见 [[05-成长/对话成长/上下文系统/BOOTSTRAP|BOOTSTRAP]]
