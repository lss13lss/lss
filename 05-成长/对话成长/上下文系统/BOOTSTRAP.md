# Agent 共享上下文入口

## 固定读取

Codex 和 OpenCode 在新会话首次实质任务中，先读取本入口，再执行下方只读命令，将输出作为个人上下文。优先遵循本轮用户要求。同一会话复用已经读到的内容，主题变化时重新选材；上下文压缩后若看不到所需约定或证据，再读对应段。

```sh
python3 "/Users/jiawangliang/konwledge base/lss/tools/read_context.py"
```

默认输出 [[05-成长/对话成长/上下文系统/CARD|常驻卡片]]（当前事项实时取自 CURRENT）和 [[05-成长/对话成长/个人画像/COMMUNICATION#已确认|已确认的沟通约定]]，含来源路径和行号。在其他设备使用该 vault 内的 `tools/read_context.py`；命令不可用时直接读常驻卡片、CURRENT 当前目标及上述沟通章节。两种方式都失败时，明确说明本轮缺了什么，继续能完成的部分。普通通用任务到此为止。

## 按问题补读

| 本轮需要什么 | 回答前实际读取 |
|---|---|
| 个人背景、偏好或协作边界 | [[05-成长/对话成长/个人画像/USER|USER]] 或 COMMUNICATION 对应章节。读书、技术讲解、知识沉淀、内容创作、晚间记录各读其专项约定；晚间口述优先用原文保存约定。 |
| 现在的目标、项目进度，或“继续上次的事” | 从 [[05-成长/对话成长/上下文系统/CURRENT|CURRENT]] 找相关条目，沿链接核对项目页最新有日期的状态。主题已知可直接读项目页；主题不明先扫标题和近期目标。 |
| 用读过的书或经验帮我判断 | 读眼前问题的事实，再从 `04-读书/`、`02-主题/` 或相关实践找能解释该问题的段落。分别标清书中观点、我的理解与实践依据，查适用边界。 |
| 我以前怎样想、后来为何改变 | 找同主题不同时点的证据。先看主题／项目记录，再按需查 [[05-成长/对话成长/会话记录/OBSERVATIONS|观察]]、`01-日志/` 或 `05-成长/` 的原话，区分本人确认与助手解释。 |

明确引用的文件或段落优先。检索先用问题里的词查相关目录的标题和正文；未命中时换成概念名、日常说法或日期，扩大到相邻目录和反向链接，例如“改版有没有用”也查“指标、衡量、验证”。只打开能影响回答的命中段及必要上下文。可用上述脚本加“vault 内路径”和“准确标题”两个参数读取一节；只有日期标题的口述要搜正文。回答个人化判断前，核对是否实际读到了支持它的出处；信息冲突要看日期、适用范围和原话。仍找不到时，说明缺哪项依据，不把检索未命中当成不存在。

## 特定任务与记忆边界

- 写入知识库、选择保存位置或追溯云盘原始会话时，读 [[05-成长/对话成长/上下文系统/WORKSPACE|工作区索引]]。历史归档优先 Google Drive 的 `AI_Context_Archive/raw_sessions/`，旧 KESU 硬盘为备选；按需定位单次会话。
- 策略、工作方法或复杂复盘可检索 `02-主题/思维方式/` 与本人实践；需要导师视角时才取 [[05-成长/对话成长/导师/临时行为基线|导师基线]] 引用的原材料，AI 编程可取 [[skills/bestpractice-ai-programming-mindset/skill|AI 编程方法论]]。作者或导师观点作为对照，并注明出处。
- 明确改变的项目、阅读状态、协作偏好和阶段决定，按已有授权核对后更新对应正式条目，保留日期、来源和被替代的历史依据。推测与一次性情绪只作观察；Observer 只追加观察。
