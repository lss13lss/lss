# 常驻卡片与加载机制修改说明

新会话先读取 [[BOOTSTRAP]]，再运行 `tools/read_context.py`。不带参数时返回 [[CARD|常驻卡片]]和 [[COMMUNICATION#已确认|已确认的沟通约定]]。卡片中的“现在在推进”从 [[CURRENT#当前目标|CURRENT 当前目标]]实时生成。

## 这次修改

- 新增 CARD，保留个人背景、事项摘要占位、知识库分类和按问题查找的入口。
- 扩展读取脚本：按 CURRENT 的三级小节提取每个列表项的加粗首句和第一个内部链接，保留链接锚点。未加粗条目回退到首句并提示；默认输出超过 2,200 字时提示但不截断。
- 精简 CURRENT 的当前目标，保留六个原有小节标题、状态与对应入口。11 月 6 日生活场景试写待审阅且未同步网页的状态已保留。当前阶段、工作与调研入口、最近的下一步三节保持原文。
- 更新 BOOTSTRAP 和 [[个人上下文如何加载]]，补充读取失败时的人工回退路径。
- 为文件名含“（本机留存）”的文件增加 Git 忽略规则。新增前核对过没有已跟踪的同名文件。

## 日常维护

1. 当前事项有变化时，先把进展和证据写入项目页，再更新 CURRENT 的对应条目。
2. 当前目标下每条以加粗摘要开头，第一个内部链接指向需要继续查看的材料。一个条目只展示第一个链接。
3. 运行 `python3 tools/read_context.py` 预览结果。卡片没有缓存，修改 CURRENT 后下次读取生效。
4. 按章节读取仍可使用 `python3 tools/read_context.py "库内路径.md" "准确标题"`。卡片缺失时，脚本仍尝试读取沟通约定并显示错误。

## 验证与边界

2026-11-09 验证通过：Python 编译、默认读取、按章节读取、缺参报错；使用临时样本检查实时摘要、范围限制、锚点、未加粗提示和卡片缺失回退。默认输出当时为 1,954 字，六个小节标题保留。全库检查有 5 个既有示例链接提示，没有新增失效链接。

附件中的 Python 代码在粘贴后发生换行截断。本次依据其逻辑恢复代码，`read_section` 的语法树与修改前一致；结果与附件给出的 MD5 不一致。原始文件备份位于本机 `~/.codex/context-card-backup-2026-11-09/`，仅在创建备份的设备上可用。

本次整理前，CURRENT 含已有的未提交更新。提交本次加载机制时，完整 CURRENT 一并纳入；其他已有未提交文件仍保留在工作区。实际多设备新会话读取效果需要各自在设备上验证。
