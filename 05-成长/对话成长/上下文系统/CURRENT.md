# 当前上下文

## 当前目标

建立一套由 Codex 与 OpenCode 共用的个人上下文系统：

1. 自动归档两边的原始对话。
2. 每次新会话自动加载精简个人上下文。
3. 从对话中逐步形成个人画像、偏好、方法和待跟进事项。
4. 暂时借用 grapeot 的 context-infrastructure 作为导师框架。
5. 当个人经验积累后，用导师框架做对照、质疑和校准，而不是继续代替个人判断。
