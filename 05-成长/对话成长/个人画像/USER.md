# 个人画像

> [!info] 状态
> 这是一份逐步生长的个人画像。只记录用户明确表达或有可核查证据支持的内容。未知部分保持未知。

## 已确认

- 主要使用中文交流。
- 时区为 Asia/Shanghai。
- 使用 Obsidian 管理个人知识库，vault 位于 `lss/`。
- 同时使用 Codex 与 OpenCode，希望两者共享一套长期上下文。
- 希望原始对话自动归档，但长期记忆只保留真正可复用的内容。
- 目前从事算法工程，近期在做 Agent 记忆相关工作。
- 偏好简短、渐进式交流，希望在互动中逐步理解系统，而不是一次接收大量说明。
- 愿意暂时借用成熟框架作为起点，同时希望逐步形成自己的判断体系。
- 希望保留原作者框架作为长期导师和对照样本，用来检查自己的思路盲区。

## 更新原则

- 当前对话中的明确陈述优先。

- 原作者的 `USER.md` 永远不参与本文件的自动填充。
