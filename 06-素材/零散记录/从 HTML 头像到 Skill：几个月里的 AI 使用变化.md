# 从 HTML 头像到 Skill：几个月里的 AI 使用变化

> [!abstract] 核心角度
> 用同一个头像设计需求，对比几个月前依靠 Google AI Studio、HTML 和几个简单技巧的做法，与现在结合新模型、Agent、Harness、Skill 等方法的做法。借这个真实案例说明：短短几个月里，AI 的能力和使用方式都发生了变化，自己接触到的技巧和方法也在变化。

## 选题来源

最开始准备做「lss在AI时代」时，想分享的内容之一，是用 Google AI Studio 写 HTML 来做头像设计。

当时之所以选择 HTML，是因为根据自己的使用感受，生图模型对文字类内容的生成还不够好，希望借助 HTML 获得更可控的文字和排版。

几个月过去，又接触到了 Agent、Harness、Skill 等新的概念和使用方法；生图与视频生成能力也在快速发展。因此想把当时的几个简单技巧和现在使用 Skill 等方法的过程放在一起比较。

## 已确定的表达重点

- 这篇作为首推之后的独立内容展开。
- 第一篇首推只简单提到：最开始曾想分享 Google AI Studio 和 HTML 头像设计。
- 第二篇通过同一个具体任务展示变化，避免只罗列新概念和模型名称。
- 账号还会记录自己在使用 AI 时接触到的新技巧、新方法，以及实际用下来的感受。
- 对比时区分三类变化：模型能力的变化、工具和工作流的变化、自己使用经验的变化。

## 初步结构

1. 几个月前，我为什么想用 HTML 做头像。
2. 当时的具体流程和几个简单技巧。
3. 当时这种做法解决了什么问题，又有哪些限制。
4. 几个月后，生图、视频和 Agent 相关工具发生了哪些变化。
5. 现在重新完成同一个头像需求，会怎样使用模型、Skill 或其他工作流。
6. 旧方法与新方法的效果、耗时、可控性和修改方式对比。
7. 哪些进步来自技术，哪些来自自己更会提需求、组织步骤和检查结果。
8. 收束到账号：继续记录新技巧、新方法和真实使用感受。
