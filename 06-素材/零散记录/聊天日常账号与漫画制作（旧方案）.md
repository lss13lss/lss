# 聊天日常账号与漫画制作（旧方案）

这是将聊天记录转成图文、漫画或短动画的旧构想。账号创意与制作流程放在一起，方便以后真要做时重用；它与 [[03-项目/账号运营/AI 账号定位|lss在AI时代]] 是不同提案，不合并为当前账号人设。

> [!info] 来源与状态
> 《聊天账号定位：》创建于 2026-04-03；《动漫生成》没有内容日期。两篇都以建议稿口吻书写，没有实施记录或效果数据；角色姓名、年龄、外貌和示例对话是模板占位，不是对用户、伴侣或真实关系的记录。

## 旧账号创意

- 主题：甜蜜、搞笑的日常聊天互动。
- 当时设想的形式：聊天截图、文字故事、对话泡泡漫画、短动画或 GIF。
- 当时假设的受众：学生、年轻职场人、情侣，以及喜欢轻松恋爱日常的观众；未有受众数据验证。
- 风格选项：调皮幽默、轻吐槽；薄荷绿/浅蓝/米白、圆润字体、清新明快。
- 备选名：憨憨日常、甜蜜上线、小两口的日常、哎呀又逗我、恋爱翻车现场。
- 主题化选题：按一类日常情境形成合集，而不只是逐张堆截图。

旧稿还建议每日 20:00—21:00 发布、前两周日更、第三周加大胜出形式。这些没有数据依据，只保留为历史实验设想。没有必要把它们变成当前排期。

## 两条制作线

先制作稳定的角色资产，再用同一套角色完成不同聊天场景。

### 角色资产线

输入：必要的参考图、外貌描述、画风、固定特征、允许变化的范围。输出：

1. 立绘：正面、45 度、侧面。
2. 表情：开心、无语、生气、害羞、惊讶等需要的表情。
3. 动作：站、坐、拿手机、挥手等常见动作。
4. 设定文档：标准描述、不可变项、可变项。

```text
角色名：【填写；不要沿用示例姓名作为真实身份】
画风：【选择一种主风格】
固定特征：【发型、脸型、服装、主配色、配饰】
气质：【填写】
不可改变：【明确哪些特征用于识别同一角色】
允许变化：表情、动作、场景、光线、视角
参考图：【文件路径】
```

可以按每个角色一个文件夹保存 `profile.md`、正面/侧面图、立绘和表情。旧稿中的“小悠、栗色短发、黄色卫衣”等只是演示设定，不带入真实人物资料。

### 内容制作线

1. 挑一段适合改编的聊天，明确哪些是真实原句、哪些是创作改写。
2. 转成 5—10 个镜头以内的小样，先检查故事是否连贯。
3. 每个镜头列出人物、地点、气氛、动作、表情、台词和构图。
4. 引用相同角色设定制作场景底图。
5. 添加对话框与文字，检查错字、发言人、遮挡和阅读顺序。
6. 保存底图、可编辑排版与导出图；如果做动画，再加动作、音轨和字幕。

## 可复用的镜头结构

```json
{
  "scene_id": "001",
  "location": "场景地点",
  "time": "时间",
  "mood": "气氛",
  "characters": [
    {"name": "角色 A", "expression": "表情", "action": "动作"}
  ],
  "dialogue": [
    {"speaker": "角色 A", "text": "已确认的台词"}
  ],
  "shot": "构图与景别",
  "notes": "角色参考、留白与阅读顺序"
}
```

```text
用途：【漫画分镜 / 聊天截图风插画 / 单张剧情卡片】
角色参考：【对应角色设定与参考图】
场景、时间与氛围：【填写】
镜头与画幅：【填写】
动作与表情：【填写】
风格：【沿用角色设定】
固定约束：【发型、脸型、服饰、配色与参考一致】
文字方案：【模型生成文字 / 无字底图后排版】
需要预留的位置：【对话框、标题等】
```

## 图像与文字是否分开

旧稿主张“无字底图 → 单独添加气泡和中文”，理由是方便纠错、统一字体和批量换台词。这仍是一个可测试的工程选项，但“生图模型中文一定不可靠”是有时间性的旧判断；选型时应拿当前工具做同一张测试图，再决定是否分离。

若分开制作，保持：发言人和气泡映射、字体、字号、边距、气泡颜色一致。可以手工排版，也可以在模板稳定后用网页或脚本完成。

## 自动化的三个层级

| 层级 | 做什么 | 适合何时尝试 |
|---|---|---|
| 人工小样 | 角色设定、出图、手动排版 | 先验证 5—10 个镜头是否好看、好读 |
| 半自动 | 表格/JSON 管分镜，固定提示词，统一排版 | 已知道哪些变量可变、哪些必须固定 |
| 批量生成 | 读角色设定→分镜→底图→气泡→导出，再检查一致性 | 小样流程稳定且确有重复需求 |

原稿建议直接采用半自动方案，但没有当前产量和质量数据支撑；保留为旧提议，不标成已决定的路线。

### 一次小样重点看什么

- 人物能否在多个镜头中保持脸型、发型和主服装一致。
- 对话顺序、文字与表情是否对应，有无因改写改变原意。
- 背景和人物是否挤占文字空间，手机上能否轻松阅读。
- 修改一句台词、一个动作、一个角色特征各要花多少时间。
- 原聊天、创作改编与生成结果是否能追溯对应。
